# Story-To-Image-Generazione-Controllata-Di-Immagini-Personalizzate

ENGLISH:
Set of Stories and Results from Sequential Image Generation via Text-to-Image and Image-to-Image (T2I/I2I). Use three different pipelines in three different modes. One for generating images is a specific target (generic, children and teenagers) - in a basic (VLM) - assisted (VLM+LLM) and extended (VLM+LLM+LLM) manner. 

To be able to configure and make everything work you need to follow the following steps:
- Go to the stability.ai site: https://platform.stability.ai/.
- Create account and log in.
- Go to the top right and go to the API keys section.
- Create a new key by clicking on "CREATE API KEY".
- Save somewhere and store the API KEY.
- Click billing (to the left of the screen under the KEYS and Account API section).
- IMPORTANT: check the credit, each photo generated with stable diffusion 3.5 medium will consume approximately 5 credits. If you have problems with the key, create another one
- Go to the google site gemini ai: https://aistudio.google.com/api-keys
- Create or log in with an account.
- Create a new key using the “Create API Key” button.
- Created the key copy and save the key.
- IMPORTANT: Check "Usage and Billing" and monitor daily or monthly usage with the specific chave (to the left of the screen under API Key). If the quota is exceeded, create another key.
- Save both keys start one of the three and enter the keys for STABILITY and GEMINI
- REMEMBER: To specify the directories of interest for the "stories to use" and the "result path" within the files.


ITALIAN:
Insieme di Storie e risultati derivanti dalla generazione di immagini sequenziali tramite Text-to-Image e Image-to-Image (T2I/I2I). Utilizzate tre pipeline diverse in tre modalità diverse. Una per la generazione di immagini uno specifico target (generico, bambini e ragazzi) , in maniera base (VLM) , Assistita (VLM+LLM) e Estesa (VLM+LLM+LLM). 

Per poter riuscire a configurare e far funzionare il tutto bisogna seguire i seguenti passaggi:
- Andare sul sito di stabilty.ai: https://platform.stability.ai/.
- Creare un account e loggarsi.
- Andare in alto a destra e andare nella sezione API keys.
- Creare una nuova key, cliccando su "CREATE API KEY".
- Salvare da qualche parte e memorizzare la API KEY.
- Cliccare su billing (a sinistra dello schermo sotto la sezione API KEYS e Account).
- IMPORTANTE: controllare il credito, ogni foto generata con stable diffusion 3.5 medium consumera circa 5 crediti. In caso di problemi con la chiave crearne un'altra
- Andare sul sito di google gemini ai: https://aistudio.google.com/api-keys
- Creare o loggarsi con un account.
- Creare una nuova chiave tramite il bottone "Crea Chiave API".
- Creata la chiave copiare e salvare la key.
- IMPORTANTE: controllare su "Usage e Billing" e monitorare l'utilizzo giornaliero o mensile con la specifica chave (a sinistra della schermata sotto Chiave API). In caso di superamento quota creare un'altra chiave.
- Salvate entrambe le chiavi avviare uno dei tre ed inserire le chiavi per STABILITY e GEMINI
- RICORDATI: Di specificare le directory di interesse per le "storie da utilizzare" e il "path dei risultati" all'interno dei file.
